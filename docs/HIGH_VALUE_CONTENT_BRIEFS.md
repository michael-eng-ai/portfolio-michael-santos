# High-Value Content Briefs

## Objective

Make the most important projects and articles easier to remember, easier to share, and easier to trust.

## Priority Assets

### Projects
- `kafka-debezium-dbt`
- `aws-databricks-lakehouse`
- `gcp-dbt-modern-data-stack`
- `streaming-kafka-fastapi`

### Articles
- `data-platform-modernization-patterns`
- `from-news-to-data-product`
- `real-time-data-architectures-in-2026-streaming-and-cdc-for-trustworthy-operational-analytics`

## Required Proof Blocks For Projects

- business pressure in plain language
- concrete architecture path
- one explicit tradeoff
- one production next step
- one business effect the reader can repeat back

## Required Proof Blocks For Articles

- a sharp opening hook tied to business pressure
- one decision rule the reader can reuse
- one linked project that acts as proof
- one operational detail that keeps the argument grounded
- one short takeaway worth sharing

## Visual Rule

Priority assets should use local brand visuals whenever possible.

The goal is to look authored, not generic.

## Resume Conversion Rule

Resume traffic is high intent.

Default the user to:

- HTML view for better reading
- print to PDF when needed
- markdown only as backup source
